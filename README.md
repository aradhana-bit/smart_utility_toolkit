# Smart Utility Toolkit

A modular JavaScript utility toolkit that brings multiple everyday tools together in one project. The toolkit is designed to provide useful utilities such as a calculator, dice roller, and file management functionality through a Node.js-based application.

## Features

- Calculator utility for performing mathematical operations
- Dice utility for generating random dice results
- File manager for handling files through the application
- Modular JavaScript structure for organized and reusable code
- Node.js server for running the application
- Easy-to-extend architecture for adding new utilities
